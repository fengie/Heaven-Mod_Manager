# Privacy Policy

**Last updated:** October 3, 2026

Universal Mod Manager / MHW Manual Mod Manager is a local-first Windows desktop application. This policy describes the current application build distributed by the project.

## What the app stores locally

The manager may store game and mod paths, enabled/disabled state, profiles, conflict decisions, provider metadata, update state, diagnostic logs, crash/support diagnostics, and optional API credentials that you explicitly configure. These files stay on your device unless you choose to send or upload them yourself.

The app has no first-party account-registration system, advertising SDK, behavioral-advertising system, or marketing-email system in the current release.

## Network activity

The app can contact third-party services when a feature requires it, including program-update sources, configured mod/catalog providers, and Nexus Mods when you configure Nexus access. Automatic or background checks can be disabled in Settings where the feature supports that control.

Those third parties can receive ordinary network metadata such as your IP address and request headers, and they process that information under their own terms and privacy policies. The app does not promise that third-party services retain no request data.

## Diagnostics and support bundles

Runtime diagnostics are written locally. A support bundle is created only when you ask for one. The manager is designed not to include mod binaries or large game files automatically, but diagnostic output can still contain paths, filenames, configuration details, or other information you consider private. Review a bundle before sharing it.

## Data minimization

The manager is designed to keep only data needed for mod management, recovery, updates, diagnostics, and user-requested provider features. It does not sell personal information and does not use local manager data to build advertising profiles.

## Cookies, advertising, reviews, payments, and marketing email

The native desktop application does not set browser cookies, display advertising, operate a consumer-review system, process payments, or send marketing email. If a future release adds any of those features, this policy and the relevant consent/opt-out surfaces must be updated before that feature ships.

## Children

The app is a general-audience desktop utility and is not directed to children under 13. The current release does not intentionally collect personal information from children through a first-party online account or service.

## Your control and deletion

You can inspect the manager-owned data location from Settings. See [DATA-DELETION.md](DATA-DELETION.md) for the supported local deletion/reset procedure and for the distinction between manager data and your durable Mods/archive folders.

## Security

The project uses signed/verified update and release-integrity controls where available, but no software or network transmission can be guaranteed perfectly secure.

## Changes to this policy

Material privacy behavior changes should update this file, the in-app Privacy & legal surface, and the compliance regression tests in the same release.
