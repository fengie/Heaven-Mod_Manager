## Reproduction / root cause
Current v8.8.55 source loads `games.json` during `GamesPageViewModel.Refresh()` and leaves general Steam/Epic/GOG discovery behind the manual `ScanInstalledGames` command. A successful MHW-specific bootstrap therefore commonly makes the Games page appear MHW-only. The existing executable fallback checks only a few fixed directories and can miss legitimate nested game executables.
