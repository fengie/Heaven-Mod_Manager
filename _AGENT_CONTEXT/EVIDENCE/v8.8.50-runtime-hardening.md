## Root causes and repairs

1. Dashboard: removed the direct `Width={Binding ViewportWidth,...}` contract from the ScrollViewer child and retained bounded `MaxWidth` with horizontal Stretch.
2. Metadata retry: the initial refresh used a permanent `initialMetadataRefreshStarted` latch while `RunBusy` swallows operation failures. A completion bit now resets the latch when the operation exits without completing.
3. Updater race: `PreparedUpdateHandoff` was cached independently of mutable `stagedProgramUpdate`. The cache now tracks the exact `StagedUpdate` object, invalidates when identity changes after a yield, and rechecks identity at the no-yield launch boundary.
4. Diagnostics privacy: startup logged raw `StartupEventArgs.Args`. `UpdateHealthProtocol` now formats diagnostic arguments and replaces values for token, health-file, and attempt flags with `<redacted>`.
